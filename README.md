Free TV Playlist for rPlayTV

This project is intended to provide a small, carefully selected playlist of free live TV channels for use with rPlayTV.

Project Goals

* Focus on free, publicly accessible live TV streams.
* Favor reliable channels that work in rPlayTV.
* Include news, classic television, entertainment, music, and family-friendly programming.
* Avoid paid or unauthorized streams.
* Keep the playlist simple and remove channels that no longer work.

Important Note

Channel availability and stream compatibility may change. Not every channel is guaranteed to work on every device or network.

Usage

Add the M3U playlist URL from this repository to rPlayTV. Test channels individually to confirm that they play correctly.

This is an independent project and is not affiliated with rPlayTV or the channel providers.
